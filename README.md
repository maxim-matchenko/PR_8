Даня М. популярен в TikTok. Стартовый капитал — n рублей (доход от первых рекламных интеграций). Каждый месяц количество подписчиков растет, а вместе с ним и доход — на p % ежемесячно. Даня мечтает накопить s рублей на собственный тур по городам. Через сколько лет Даня М. сможет отправиться в тур? 
Контрольные данные №1 
initialCapital=1000
monthlyGrowthPercent=5
stargetAmount=100000
Ответ: 3,1 года
Хотите выполнить программу еще раз? ( да-1/нет-любая клавиша): 1 
Контрольные данные №2 
n=a 
Ответ консоли: красным цветом — что-то пошло не так. Ошибка: входная строка имела неверный формат. 
Контрольные данные №3
initialCapital=-1000
monthlyGrowthPercent=5
stargetAmount=100000
Ответ консоли: красным цветом — что-то пошло не так. Ошибка: Введенные значения должны быть больше нуля!
